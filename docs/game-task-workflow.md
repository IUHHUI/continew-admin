2. 生成任务
3. 任务放到redis队列才会被调度到云手机

6. 登录成功后, 放到任务执行队列A, 普通执行, 如果任务执行队列B有优先执行

登录成功前, redis任务使用cami
登录成功后, 生成任务,使用taskId
用户打开登录页面, 填写信息后, 如果自己是一个新的任务, 需要等待空闲的上号机器.

设备上传状态

1. 新设备,增加设备信息到mysql
2. 设备根据类型获取登录任务或者游戏任务

获取登录任务

1. 设备有任务在执行, 不需要获取任务
2. 从standby 队列获取卡密id, 放到running 队列
3. running队列,卡密

云手机执行登录任务
云手机状态空虚,接到密码登录任务后, 执行.状态转执行中, 执行成功, 上报执行成功. 执行失败,上报执行失败.
云手机状态运行中, 不处理任何任务 .
云手机状态失败, 如果任务数据没有更新, 不继续处理. 如果更新,继续处理.
云手机状态成功, 如果是两阶段登录任务, 等待下一个阶段 目前只有二维吗和验证码. 如果是阶段2成功, 标记任务成功, redis 移除卡密.
二维码等待自动来到阶段2.
验证码, 下发二阶段的任务.

云手机状态空虚,接到密码登录任务后, 执行.状态转执行中, 执行成功, 上报执行成功. 执行失败,上报执行失败.
